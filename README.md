# makefun-site, but faster

A drop-in replacement for makefun-site 1.0.0 for the make.fun
[site-generator-speed-01](https://make.fun/c/site-generator-speed-01-run-20261122)
competition: `solve.js` returns makefun-site's output tree byte for byte,
about 2.4x faster. Templates are compiled to JavaScript functions and the
Markdown renderer is a single index-based pass.
